# くじ検証 (kuji-kensho)

抽選の結果を、主催者以外の誰でもあとから再計算して確かめられるくじ引きツールです。

- 公開版: https://kuji-kensho.vercel.app
- サーバなし。くじの中身はすべて URL の `#` より後ろに入っています(`#` 以降はサーバに送られません)

## つかいかた

1. **封をする**(主催者): くじの名前と当選人数を入れると、ブラウザが 256 ビットの「種」を作り、そのハッシュ入りの告知文を出します。告知文は SNS など全員が同じものを見る場所に1回だけ投稿します。種の入った控えURLは誰にも見せません
2. **締め切る**: 応募を締め切り、名簿(1行に1人)を控えページに入れます
3. **封を開ける**: 種が明かされた結果URLができます。参加者はそれを開くと、告知のハッシュとの照合・当選者の再計算・名簿に自分の名前があるかを確かめられます。告知を見たのと同じ端末なら照合は自動です

## しくみ

| 段階 | 内容 | ファイル |
|---|---|---|
| 封筒 | `kuji-kensho/v1 winners=<人数> seed=<16進64桁>` の SHA-256 を先に公開する。当選人数も封の中 | `src/lib/lottery.js` |
| 名簿 | NFC・空白をまとめる・空行除去・**コードポイント順に並べ替え**・改行でつなぐ。入力の順番は結果に影響しない。重複は拒否 | `src/lib/roster.js` |
| 乱数 | `kuji-kensho/v1 draw seed=<種> roster=<名簿のハッシュ> block=<i>` の SHA-256 を4バイトずつ 32 ビット整数として読む | `src/lib/lottery.js` |
| 抽選 | 先頭から Fisher–Yates。`2^32 − (2^32 mod n)` 以上の値は捨てて引き直す(棄却サンプリングで剰余の偏りを除く) | `src/lib/lottery.js` |
| 検証 | 封・告知のハッシュ・名簿・発表された当選者を、手元で全部計算し直して照合する | `src/lib/verify.js` |

### 防げること・防げないこと

- 防げる: 結果を見てから種を選び直す / あとから当選人数を変える / 名簿の並べ替えで結果を変える
- 見抜けるが防げない: 種を明かさず中止する / 人によって違うハッシュを告知する / 細工した検証ページを見せる
- **この方式では防げない**: 主催者は種を知っているので、締め切り前に名簿へサクラを足したり人を消したりして、当てたい人が当たるまで手元で試せる(およそ「応募数 ÷ 当選人数」通り)。締め切り時点の名簿を公開し、応募の受付を主催者以外も見える場所で行うしかありません

## アプリを使わずに確かめる

```bash
# 封のハッシュだけ
printf %s 'kuji-kensho/v1 winners=2 seed=<種>' | shasum -a 256
# 当選者まで(依存なし・アプリ本体のコードを使わない独立実装)
node scripts/verify.mjs '<結果URL>'
```

## 開発

```bash
pnpm install
pnpm dev            # http://localhost:5930
pnpm test           # 同じテストを Node と Chromium(Vitest browser mode)の両方で実行
node scripts/smoke.mjs http://localhost:5930/   # ヘッドレスで一通りの流れを確認
```

- 初回のみ `pnpm exec playwright install chromium-headless-shell` が必要です
- 固定ベクトル(`test/vectors.json`)は Python の別実装で作った期待値です。本体・独立検証スクリプト・Python の3つが一致することを固定しています
- `window.__app` に `demo()`・`lib`・`state` を出しています(ヘッドレス確認用)
